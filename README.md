# One-Sentence Absurd Invention Pitch

Entry for make.fun bounty `u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a`.

`main.py` (pure Python stdlib) writes one sentence to `/output/entry.txt`:

> Headphones that pause your music on the third 'uh-huh' of a call you aren't listening to, and resume only after you repeat the last sentence verbatim.

150 characters, one line, UTF-8 — inside the 1–220 character gate.
